# Curriculum: Mid/Senior LLD & System Design

## Phase 1: Architecture & Domain Modeling
1. **SOLID, DI, and Clean Architecture**: Isolating the core domain from infrastructure, applying IoC effectively.
2. **Domain-Driven Design (DDD) Basics**: Entities, Value Objects, Aggregates, and Repositories in C#.

## Phase 2: Data & Contracts
3. **Database Schema & Entity-Relationship Modeling**: Mapping objects to relational tables, managing DB concurrency (Optimistic/Pessimistic locking), and indexing.
4. **API Design & Contracts**: RESTful best practices, idempotency keys, handling partial failures and retries.

## Phase 3: Advanced Machine Coding
5. **In-Memory Message Queue**: Implementing Pub/Sub with Topics, Partitions, and Consumer Groups.
6. **Task Scheduler / Job Executor**: Managing delayed/recurring execution and background thread pools.
7. **Complex Domains (e.g., Splitwise)**: Graph algorithms combined with rich domain modeling.

## Phase 4: Distributed Systems (HLD)
8. **High-Level System Design**: Microservices, CAP Theorem, Event-Driven Architectures (Kafka/RabbitMQ), and Database Sharding.
